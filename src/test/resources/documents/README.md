# Synthetic PDF fixtures

Generated locally by `PdfFixtures` in test sources. Text and raster pages contain
only the synthetic phrase “Readable Markdown” and sample lines. No personal or
third-party book is included. `corrupt.pdf` deliberately has no valid PDF structure.

The generator also creates 240-page digital/scanned fixtures under
`build/stage7-host/fixtures` for host validation; these reuse page content and do
not represent the size or complexity of a real scanned book.
